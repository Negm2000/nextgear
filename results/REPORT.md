## 4. What if the agent had done something else?

At every decision point of the first 400 test sessions (7990 points), each model predicts the check's verdict for all sixteen gears and for a submission. The checks give the true answer. 120834 gear queries are actions the agent did not take; 56% of those would have been rejected.

| Model | Right verdict, untaken gears | Gear verdict log loss | P(pass) if forced to submit | Submit log loss |
|---|---:|---:|---:|---:|
| n-gram (6) | 92.58% | 0.2283 | 9.0% | 0.7780 |
| State counts | 75.72% | 0.5656 | 14.7% | 0.6427 |
| GRU | 99.76% | 0.0085 | 4.8% | 0.1776 |
| Oracle | 100.00% | 0.0000 | 4.7% | 0.1174 |
| Oracle with do() | 100.00% | 0.0000 | 4.7% | 0.0885 |

Forced submissions pass 4.7% of the time. In the logs, an agent submits when it believes the assembly is ready, so a model trained on them learns what follows a submission that is evidence of readiness. A forced submission carries no such evidence. The oracle without do() still treats it as an observation; the oracle queried with do() does not, and the difference between their submit log losses measures what that evidence is worth here. These what-if figures are descriptive; no intervals are reported for them.

## 6. A requirement combination never seen in training

The count models and a GRU were refit without them, then scored on 600 new sessions of exactly that kind. "GRU" is the normal model, which did see such sessions. The oracle keeps the base prior and is not told that the evaluation sessions come from this group. It is a common reference, not the best score available to a predictor that knew the group. Model settings and the n-gram context are reused from the main experiment, where they were chosen on validation data that included this group, so this is an exploratory exclusion test rather than an untouched holdout.
